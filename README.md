# ✂️ Генератор шаблонов коробок
https://koksasa.github.io/boxcutter/

Генератор крестообразных заготовок для коробок из картона с крышкой. Экспорт шаблонов в **DXF** для лазерной резки.

## Возможности

- 📦 Ввод габаритов товара → автоматический подбор размера коробки
- 📐 Расчёт внутренних и внешних размеров с учётом толщины картона
- 🎛️ Настраиваемые зазоры для крышки и вкладышей
- 📥 Экспорт в **DXF** (слои CUT — рез, SCORE — сгиб)
- 👁️ Интерактивный 3D-предпросмотр коробки
- 🖼️ SVG-предпросмотр развёртки

## Как использовать

1. Укажите размеры товара и зазоры — нажмите **«Подобрать размер коробки»**
2. Или задайте внутренние размеры вручную
3. Настройте толщину картона и параметры крышки
4. Скачайте DXF:
   - **Коробка + крышка** — оба шаблона
   - **Только коробка**
   - **Только крышка**

## Слои DXF

| Слой | Назначение |
|------|-----------|
| `CUT` | Линии реза (непрерывная) |
| `SCORE` | Линии сгиба (пунктир) |

## Запуск

Откройте `index.html` в браузере — всё работает без сервера.
